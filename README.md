# ✅ Taskify

A task management application built with React that supports drag-and-drop functionality between task columns.

---

## 🚀 Features

- Create and manage tasks
- Drag and drop tasks between columns
- Component-based architecture
- Clean and minimal UI

---

## 🛠️ Tech Stack

- **React**
- **TypeScript**
- **@hello-pangea/dnd**

---

## 🚀 Live Demo

[👉 Visit the demo](https://taskify-fawn-ten.vercel.app/)

---

## 📦 Installation and Setup

Clone the repository:

```bash
git clone https://github.com/NazarStepaniuk/taskify.git
cd taskify
npm install
npm start
```
